# Background images

Put nine 480 × 480 PNG files here. They are not part of the repository.

| File | Shown for |
|---|---|
| `sonne.png` | sunny |
| `nacht.png` | clear night |
| `wolkig.png` | partly cloudy, windy-variant |
| `bedeckt.png` | cloudy, fog, windy, exceptional |
| `regen.png` | rainy, pouring |
| `gewitter.png` | lightning, lightning-rainy, hail |
| `schnee.png` | snowy, snowy-rainy |
| `platte.png` | turntable playing without a recognized cover |
| `cd.png` | CD or other MasterLink source without a recognized cover |

Dark, low-contrast pictures work best: title and temperature are drawn on top.
